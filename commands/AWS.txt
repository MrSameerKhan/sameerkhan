------------------------- EC2 -----------------------------

1. Launch instance
Key Pair: Create (e.g., sameer-key.pem)
Security Group:Allow ports: 22 (SSH), 8000 (FastAPI)
Click “Add Rule” below the existing SSH rule
Tag: Project: sentiment-api

2. Connect to instance
chmod 400 sameer-key.pem
ssh -i sameer-key.pem ubuntu@<your-ec2-ip>


3. Install packages
sudo apt update && sudo apt upgrade -y
sudo apt install python3-pip python3-venv git -y
python3 -m venv venv
source venv/bin/activate
pip install --upgrade pip
pip3 install transformers torch fastapi uvicorn

4. Create app.py(move from local)
scp -i sameer-key.pem \
  /Users/sameerkhan/Desktop/sameerkhan/cloud/sentiment-api/app.py \
  ubuntu@13.204.45.223:~/sentiment-api/


5. Run FastAPI Server
ssh -i sameer-key.pem ubuntu@13.204.45.223
cd ~/sentiment-api
source venv/bin/activate
uvicorn app:app --host 0.0.0.0 --port 8000

6. stop instance
aws ec2 stop-instances --instance-ids i-08419f0739e637567
aws ec2 terminate-instances --instance-ids i-08419f0739e637567
