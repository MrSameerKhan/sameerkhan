# What is a Gradient?

A gradient is:

∂L / ∂W

It tells us how much a small change in a weight changes the loss.

During backpropagation, gradients are computed using the **chain rule**, which multiplies derivatives layer by layer.

This repeated multiplication is exactly where vanishing and exploding gradients come from.

---

# 1️⃣ Vanishing Gradients

## Definition

Gradients become extremely small as they propagate backward through many layers.

Early layers receive updates like:

- 10⁻⁶  
- 10⁻⁹  
- 10⁻¹²  

Effect:

- Weights barely change  
- Early layers stop learning  
- Training becomes very slow  

---

## Why It Happens

In deep networks:

∂L/∂a¹ = ∂L/∂aᴸ × Wᴸ × Wᴸ⁻¹ × ... × W² × (activation derivatives)

If many of these terms have magnitude < 1, repeated multiplication shrinks toward zero.

Example:

0.5 × 0.5 × 0.5 × 0.5 × 0.5 = 0.03125

Go deeper:

0.5¹⁰ = 0.000976

This collapses quickly.

---

## Common Causes

- Sigmoid saturation  
- Tanh saturation  
- Small weight initialization  
- Deep networks without residual connections  

---

## Interview Answer

Vanishing gradients occur when repeated chain rule multiplications across many layers shrink gradients toward zero, preventing early layers from learning. This commonly happens with saturating activations like sigmoid or tanh.

---

# 2️⃣ Exploding Gradients

## Definition

Gradients become extremely large as they propagate backward.

Example:

1.5 × 1.5 × 1.5 × 1.5 × 1.5 = 7.6  
1.5¹⁰ ≈ 57  

Effect:

- Huge weight updates  
- Training instability  
- Loss becomes NaN  
- Model diverges  

---

## Why It Happens

Same chain rule multiplication — but now terms are > 1.

Repeated multiplication grows exponentially.

---

## Common Causes

- Large weight initialization  
- Large learning rate  
- Long recurrent sequences  
- No gradient clipping  

---

## Interview Answer

Exploding gradients occur when repeated multiplications during backprop amplify gradients exponentially, causing unstable updates. Techniques like gradient clipping and proper initialization are used to control this.

# Computational Graph

## What Is It?

A computational graph is a directed graph showing how outputs are computed from inputs and weights.

Nodes = values or operations  
Edges = dependencies  

Example:

x → a = W1x → b = W2a → c = W3b → ŷ → L

Backpropagation simply traverses this graph in reverse.

---

## Did We Cover It?

Yes.

In our multi-layer example:

Forward pass stored intermediate values (a, b, c, ŷ).  
Backward pass moved backward applying chain rule step-by-step.

That is computational graph thinking.

---

# Gradient Flow

## What Is It?

Gradient flow describes how the error signal moves backward through layers.

Forward:
data flows →

Backward:
gradients flow ←

In dense layers:

- Gradients split  
- Gradients sum  

Key formula:

grad_in = Wᵀ × grad_out

---

## Did We Cover It?

Yes — very strongly.

Example from our dense network:

∂L/∂b₁ = ∂L/∂c₁·w₃₁ + ∂L/∂c₂·w₃₃

That shows gradients summing from multiple downstream paths.

That is pure gradient flow.

# Vanishing and Exploding Gradients  
*(Understanding using our Multi-Layer Fully Connected Neural Network example)*

---

# 1. Why This Topic Exists

After adding **activation functions**, we created a deep neural network capable of learning non-linear relationships.

However, a new problem appears during **backpropagation**:

Gradients may become:

- **Extremely small → Vanishing Gradients**
- **Extremely large → Exploding Gradients**

Both problems make training unstable.

These problems arise because **gradients propagate through many multiplications** during backpropagation.

---

# 2. Where Do Gradients Come From?

During training we compute:


∂L / ∂W


This tells us how much changing a weight affects the loss.

Backpropagation computes this using the **chain rule**.

For a deep network:


x → Layer1 → Layer2 → Layer3 → Layer4 → Loss


Backward:


∂L/∂Layer1 =
∂L/∂Layer4 ×
∂Layer4/∂Layer3 ×
∂Layer3/∂Layer2 ×
∂Layer2/∂Layer1


So gradients involve **repeated multiplications**.

---

# 3. Mental Model

Think of gradients like **water flowing backward through pipes**.


Loss
↑
Layer4
↑
Layer3
↑
Layer2
↑
Layer1


If pipes shrink → flow disappears → **vanishing**

If pipes expand → flow explodes → **exploding**

---

# 4. Vanishing Gradients

## Definition

Gradients become **extremely small** as they propagate backward through layers.

Example:


0.5 × 0.5 × 0.5 × 0.5 × 0.5


Result:


0.03125


Deeper network:


0.5^10 ≈ 0.00097


So earlier layers receive almost **zero updates**.

---

## Effect

Early layers stop learning.

Training becomes slow or impossible.

Only later layers learn.

---

## Toy Example Using Our Network

Suppose every layer multiplies gradient by **0.5**.

Backward flow:


Layer4 gradient = 1
Layer3 gradient = 0.5
Layer2 gradient = 0.25
Layer1 gradient = 0.125


If the network is deeper:


Layer10 gradient ≈ 0


So gradients vanish.

---

## Causes

Vanishing gradients often happen with:

### Sigmoid

Derivative:


σ'(x) = σ(x)(1 − σ(x))


Maximum value:


0.25


So gradients shrink every layer.

---

### Tanh

Also saturates when input is large.

Derivative approaches **0**.

---

# 5. Exploding Gradients

## Definition

Gradients become **extremely large** during backpropagation.

Example:


1.5 × 1.5 × 1.5 × 1.5 × 1.5


Result:


7.6


Deeper network:


1.5^10 ≈ 57


Gradients explode quickly.

---

## Effect

Training becomes unstable.

Weights update too aggressively.

Loss may become:


NaN


or diverge.

---

## Toy Example

Suppose gradient multiplies by **2** each layer.


Layer4 gradient = 1
Layer3 gradient = 2
Layer2 gradient = 4
Layer1 gradient = 8


Deep network:


Layer10 gradient = 1024


Exploding updates.

---

# 6. Why Deep Networks Cause This

Recall gradient propagation in dense layers:


grad_input = Wᵀ × grad_output


Each layer multiplies by weights and activation derivatives.

Repeated multiplication causes:


product of many numbers


If numbers < 1 → vanish  
If numbers > 1 → explode

---

# 7. Did We See This in Our FC Network?

Yes, indirectly.

When we inserted **ReLU**, some neurons had negative outputs:


ReLU(x) = 0
ReLU'(x) = 0


During backpropagation:


gradient × 0 = 0


So gradients stopped flowing.

This is a **practical form of vanishing gradient** called:


Dying ReLU


---

# 8. How Deep Learning Solves This

Several techniques help stabilize gradients.

---

## 1. ReLU Activation

Derivative:


ReLU'(x) = 1 if x > 0


This avoids shrinking gradients like sigmoid.

---

## 2. Proper Weight Initialization

Examples:

- Xavier initialization
- He initialization

These control variance across layers.

---

## 3. Gradient Clipping

Used to prevent exploding gradients.

Example:


if ||gradient|| > threshold:
gradient = threshold


Common in RNN training.

---

## 4. Normalization

Examples:

- Batch Normalization
- Layer Normalization

These stabilize activation distributions.

---

## 5. Residual Connections

Used in ResNet and Transformers.

They allow gradients to bypass layers.

# 10. Interview Explanation

**What are vanishing and exploding gradients?**

> During backpropagation, gradients are propagated through multiple layers using the chain rule. If repeated multiplications shrink the gradient toward zero, it results in vanishing gradients. If they grow exponentially, it leads to exploding gradients. Both make training deep networks difficult.

---

# 11. Interview Follow-Up Questions

### Q1: Why do sigmoid networks suffer from vanishing gradients?

Because the sigmoid derivative is always less than 0.25, so repeated multiplication shrinks gradients rapidly.

---

### Q2: Why is ReLU better for deep networks?

ReLU maintains a derivative of 1 for positive inputs, preventing gradient shrinkage.

---

### Q3: How do we fix exploding gradients?

Common techniques include gradient clipping, proper weight initialization, and normalization layers.
