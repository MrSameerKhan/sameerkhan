# 7. Weight Update (Gradient Descent)



## What it is
After backpropagation gives us gradients  
$\frac{\partial L}{\partial W}, \; \frac{\partial L}{\partial b}$,  
we update weights in the **opposite direction of the gradient** (to minimize loss).  



## The Update Rule

For each parameter:

$$
W \leftarrow W - \eta \cdot \frac{\partial L}{\partial W}
$$

$$
b \leftarrow b - \eta \cdot \frac{\partial L}{\partial b}
$$

Where:
- **W** = weights  
- **b** = bias  
- **η** = learning rate  
- $\frac{\partial L}{\partial W}$ = gradient from backprop  


## Role of Learning Rate (η)

- **Too small** → very slow learning  
- **Too large** → overshoots, oscillates, may diverge  
- **Good choice** → steady convergence  
- Modern optimizers **adapt η automatically**  



## Variants of Gradient Descent

- **Batch Gradient Descent**  
  - Uses the whole dataset per update.  
  - Stable but **very slow**.  

- **Stochastic Gradient Descent (SGD)**  
  - Updates after **each sample**.  
  - Noisy but faster, helps escape local minima.  

- **Mini-Batch Gradient Descent (most common)**  
  - Uses **small batches** (e.g., 32/64 samples).  
  - Balance of efficiency + stability.  



## Optimizer Improvements

- **Momentum** → adds memory of past gradients → smoother updates.  
- **RMSProp** → scales learning rate by gradient history.  
- **Adam** → combines Momentum + RMSProp (default choice in DL).  

- **AdamW** → (Adam with decoupled weight decay)  
  - Fixes a subtle issue in Adam where **L2 regularization** was implemented as “L2 penalty on gradients” instead of true weight decay.  
  - In AdamW, weight decay is applied **directly to the weights**, independent of the gradient update.  
  - This leads to better generalization, especially in deep networks and transformers.  
  - Today, **AdamW is the default** choice for training large neural networks.  


## Big Picture

1. **Forward pass** → predict  
2. **Loss function** → compare  
3. **Backpropagation** → compute gradients  
4. **Weight update (GD/SGD/Adam)** → learn  
5. **Repeat** for many epochs until convergence  

## Interview Soundbite

“After backpropagation computes gradients, we update weights using gradient descent.  
Each weight is adjusted by subtracting a fraction (learning rate × gradient).  
Using mini-batches and optimizers like Adam makes training stable and efficient.”
