# Optimizers in Neural Networks  
*(With a full end-to-end toy example using our multi-layer fully connected neural network idea)*

---

# 1. Why Optimizers Exist

During training we compute gradients using backpropagation:


∂L / ∂W


This tells us **how loss changes when weights change**.

But gradients alone are not enough.

We must decide **how to update weights**.

Optimizers define the **rule for updating parameters**.


W_new = W_old - learning_rate × gradient


Without an optimizer, gradients are useless.

---

# 2. Mental Model

Imagine a **mountain landscape**.


Height = Loss
Position = Model parameters


Goal:


Find the lowest valley (minimum loss)


Optimizers decide **how we move downhill**.

---

# 3. Basic Optimizer: Gradient Descent

Gradient Descent update rule:


W = W - η * ∂L/∂W


Where


η = learning rate


Meaning:

Move **opposite to gradient direction**.

---

# 4. Full End-to-End Toy Example  
*(You should memorize this workflow)*

We will train a **very small neural network**.

Architecture:


Input → Linear → ReLU → Linear → Output


---

## Training Data


x = 1
y = 2


---

## Initial Weights

Layer 1:


w1 = 0.5
w2 = -0.3


Layer 2:


w3 = 0.8
w4 = 0.2


Learning rate:


lr = 0.1


---

# Step 1 — Forward Pass

### Layer 1


z1_1 = w1 * x = 0.5
z1_2 = w2 * x = -0.3


ReLU activation:


a1 = max(0,0.5) = 0.5
a2 = max(0,-0.3) = 0


---

### Layer 2


y_hat = w3a1 + w4a2

y_hat = 0.80.5 + 0.20

y_hat = 0.4


---

# Step 2 — Compute Loss

Using MSE:


L = 0.5 (y_hat - y)^2

L = 0.5 (0.4 - 2)^2

L = 0.5 ( -1.6 )^2

L = 1.28


---

# Step 3 — Backpropagation

First gradient:


dL/dy_hat = y_hat - y

dL/dy_hat = -1.6


---

## Gradients for Output Weights


dL/dw3 = dL/dy_hat * a1

dL/dw3 = (-1.6)(0.5)

dL/dw3 = -0.8


---


dL/dw4 = dL/dy_hat * a2

dL/dw4 = (-1.6)(0)

dL/dw4 = 0


---

## Propagate Gradient Back


dL/da1 = dL/dy_hat * w3

dL/da1 = (-1.6)(0.8)

dL/da1 = -1.28


---

ReLU derivative:


ReLU'(0.5) = 1


So


dL/dz1_1 = -1.28


---


dL/dw1 = dL/dz1_1 * x

dL/dw1 = (-1.28)(1)

dL/dw1 = -1.28


---

Second neuron:


ReLU'(-0.3) = 0


So


dL/dw2 = 0


Neuron is dead.

---

# Step 4 — Optimizer Update (Gradient Descent)

Update rule:


W = W - lr * gradient


---

## Update w1


w1 = 0.5 - 0.1*(-1.28)

w1 = 0.628


---

## Update w2


w2 = -0.3 - 0.1*(0)

w2 = -0.3


---

## Update w3


w3 = 0.8 - 0.1*(-0.8)

w3 = 0.88


---

## Update w4


w4 = 0.2 - 0

w4 = 0.2


---

# Step 5 — Training Loop

Next iteration uses new weights:


w1 = 0.628
w2 = -0.3
w3 = 0.88
w4 = 0.2


Then we repeat:


Forward
Loss
Backward
Update


Until convergence.

---

# 5. Limitations of Basic Gradient Descent

Problems:

1. Slow convergence  
2. Oscillations in steep valleys  
3. Same learning rate for all parameters  

This led to more advanced optimizers.

---

# 6. Major Optimizers

---

## SGD (Stochastic Gradient Descent)

Instead of using the entire dataset:


update using one example or mini-batch


Advantages:

- faster
- noisy updates help escape local minima

---

## Momentum

Idea:

Add velocity to updates.


v = βv + gradient
W = W - lr * v


Like a ball rolling downhill.

Benefits:

- smoother convergence
- reduces oscillations

---

## RMSProp

Adapts learning rate based on gradient magnitude.


cache = β cache + (1-β) gradient²


Update:


W = W - lr * gradient / sqrt(cache)


Helps when gradients vary across parameters.

---

## Adam (Most Popular)

Combines **Momentum + RMSProp**.

Tracks:


gradient mean

gradient variance


Update rule roughly:


m = momentum estimate
v = variance estimate

W = W - lr * m / sqrt(v)


Advantages:

- fast convergence
- adaptive learning rates
- stable training

---

# 8. Interview Explanation

**What is an optimizer?**

> An optimizer is an algorithm that updates neural network parameters using gradients to minimize the loss function during training.

---

# 9. Interview Questions

### Q1

Why do we need optimizers?

Answer:

Gradients only indicate direction of improvement; optimizers determine how parameters should be updated.

---

### Q2

Why is Adam widely used?

Answer:

Adam combines momentum and adaptive learning rates, leading to faster and more stable convergence.

---

### Q3

Difference between GD and SGD?

GD uses full dataset per update.  
SGD updates weights using a single example or mini-batch.
