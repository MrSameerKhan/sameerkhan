# Multi-Layer Fully Connected Neural Network  
## Step-0 Forward and Backward Pass (With Real Numbers)

---

# 0) Network Definition (Fully Connected)

## Architecture

Input (1 neuron)  
→ Layer 1 (2 neurons)  
→ Layer 2 (2 neurons)  
→ Layer 3 (2 neurons)  
→ Output (1 neuron)

No activation functions (pure linear)  
No bias (for clarity)

---

## Neuron Names

Layer 1 outputs:  
a1, a2  

Layer 2 outputs:  
b1, b2  

Layer 3 outputs:  
c1, c2  

Output:  
ŷ  

---

## Forward Equations

a = W1 x  
b = W2 a  
c = W3 b  
ŷ = W4 c  

Loss:

L = 0.5(ŷ − y)²  

---

# 1) Step-0: Set Real Numbers

Given:

x = 1.0  
y = 2.0  

---

## Layer 1 (2×1)

W1 =  
[ 0.5  
 -0.3 ]

So:

w11 = 0.5  
w12 = -0.3  

---

## Layer 2 (2×2)

W2 =  
[ 0.8   -0.1  
  0.2    0.4 ]

---

## Layer 3 (2×2)

W3 =  
[ -0.4   0.3  
   0.7  -0.2 ]

---

## Output Layer (1×2)

W4 =  
[ 0.6   -0.1 ]

---

# 2) STEP-0 FORWARD PASS (Numbers Flow →)

## Layer 1

a1 = 0.5 × 1 = 0.5  
a2 = -0.3 × 1 = -0.3  

a = [0.5, -0.3]

---

## Layer 2

b1 = 0.8(0.5) + (-0.1)(-0.3)  
b1 = 0.4 + 0.03 = 0.43  

b2 = 0.2(0.5) + 0.4(-0.3)  
b2 = 0.1 − 0.12 = -0.02  

b = [0.43, -0.02]

---

## Layer 3

c1 = (-0.4)(0.43) + 0.3(-0.02)  
c1 = -0.172 − 0.006 = -0.178  

c2 = 0.7(0.43) + (-0.2)(-0.02)  
c2 = 0.301 + 0.004 = 0.305  

c = [-0.178, 0.305]

---

## Output

ŷ = 0.6(-0.178) + (-0.1)(0.305)  
ŷ = -0.1068 − 0.0305  
ŷ = -0.1373  

---

## Loss

Error:

e = ŷ − y  
e = -0.1373 − 2 = -2.1373  

Loss:

L = 0.5 × (-2.1373)²  
L = 2.284025645  

---

# 3) STEP-0 BACKWARD PASS (Error Flows ←)

Start from:

dL/dŷ = ŷ − y = -2.1373  

---

## A) Output Layer Gradients

ŷ = w41 c1 + w42 c2  

### Weight Gradients

dL/dw41 = (-2.1373)(-0.178) = 0.3804394  

dL/dw42 = (-2.1373)(0.305) = -0.6518765  

---

### Error Passed to Layer 3

dL/dc1 = (-2.1373)(0.6) = -1.28238  

dL/dc2 = (-2.1373)(-0.1) = 0.21373  

---

## B) Layer 3 Gradients

c1 = w31 b1 + w32 b2  
c2 = w33 b1 + w34 b2  

### Weight Gradients

dL/dw31 = (-1.28238)(0.43) = -0.5514234  
dL/dw32 = (-1.28238)(-0.02) = 0.0256476  

dL/dw33 = (0.21373)(0.43) = 0.0919039  
dL/dw34 = (0.21373)(-0.02) = -0.0042746  

---

### Error Passed to Layer 2

dL/db1 = (-1.28238)(-0.4) + (0.21373)(0.7)  
dL/db1 = 0.662563  

dL/db2 = (-1.28238)(0.3) + (0.21373)(-0.2)  
dL/db2 = -0.42746  

---

## C) Layer 2 Gradients

b1 = w21 a1 + w22 a2  
b2 = w23 a1 + w24 a2  

### Weight Gradients

dL/dw21 = (0.662563)(0.5) = 0.3312815  
dL/dw22 = (0.662563)(-0.3) = -0.1987689  

dL/dw23 = (-0.42746)(0.5) = -0.21373  
dL/dw24 = (-0.42746)(-0.3) = 0.128238  

---

### Error Passed to Layer 1

dL/da1 = (0.662563)(0.8) + (-0.42746)(0.2)  
dL/da1 = 0.4445584  

dL/da2 = (0.662563)(-0.1) + (-0.42746)(0.4)  
dL/da2 = -0.2372403  

---

## D) Layer 1 Gradients

a1 = w11 x  
a2 = w12 x  

Since x = 1:

dL/dw11 = 0.4445584  
dL/dw12 = -0.2372403

# 4) Backpropagation Rules (Universal)

For any linear layer:

out = W · in  

Backprop uses two rules:

## Rule 1 — Weight Gradient

gradient = (incoming error) × (input activation)

## Rule 2 — Error Propagation

error_to_previous_layer = Wᵀ × incoming_error

---

# 5) Bias Gradients (If Added)

If:

out = W · in + b  

Then:

dL/db = incoming_error  

Bias gradient equals neuron’s error.

---

# Key Insight

Every weight gradient in the entire network follows:

Gradient = Error × Signal
