# Normalization in Neural Networks  
## Batch Normalization (BatchNorm) and Layer Normalization (LayerNorm)

This topic appears after learning:


Forward → Loss → Backpropagation → Activation → Vanishing/Exploding Gradients
→ Weight Initialization → Optimizers → Learning Rate → Regularization
→ Normalization


Normalization improves **training stability and convergence** in deep neural networks.

---

# 1. Why Normalization Exists

During training, the distribution of activations in a neural network keeps changing.

Example:


Layer1 output distribution → shifts during training
Layer2 receives unstable inputs
Layer3 receives even more unstable inputs


This problem is called:


Internal Covariate Shift


Meaning:


Each layer must constantly adapt to changing input distributions.


This slows down learning.

Normalization stabilizes the distribution of activations.

---

# 2. Mental Model

Imagine students taking an exam.

One class:


Scores: [10, 20, 30, 40, 50]


Another class:


Scores: [100, 200, 300, 400, 500]


If we normalize:


Both classes become comparable.


Normalization makes data:


mean ≈ 0
variance ≈ 1


This stabilizes learning.

---

# 3. Where Normalization Happens

In our multi-layer network:


x → Linear → ReLU → Linear → ReLU → Linear → Output


With normalization:


x → Linear → BatchNorm → ReLU → Linear → BatchNorm → ReLU → Output


Normalization occurs **between linear layers and activations**.

---

# 4. Batch Normalization

BatchNorm normalizes activations **across a mini-batch**.

Given activations from a batch:


x1, x2, x3, ..., xn


Compute:


mean = μ = average(x)
variance = σ²


Normalize:


x̂ = (x − μ) / √(σ² + ε)


Then apply learnable scaling:


y = γ x̂ + β


Where:


γ = learnable scale
β = learnable shift


So BatchNorm does not restrict the model permanently.

It allows the network to learn optimal scaling.

---

# 5. Toy Example

Batch of activations:


[2, 4, 6, 8]


Mean:


μ = 5


Variance:


σ² = 5


Normalized:


[-1.34, -0.45, 0.45, 1.34]


Now activations are centered around zero.

---

# 6. Benefits of Batch Normalization

BatchNorm provides several advantages:


Faster training

Reduced vanishing gradients

Allows higher learning rates

Adds slight regularization


It stabilizes gradient flow across layers.

---

# 7. Problem with BatchNorm

BatchNorm depends on **batch statistics**.

This creates problems when:


batch size is very small


Example:


Transformer models
RNNs
small batch training


To solve this, we use **Layer Normalization**.

---

# 8. Layer Normalization

LayerNorm normalizes **within a single sample** instead of across a batch.

Example vector:


[2, 4, 6, 8]


Compute mean and variance across the **features of the same sample**.

Formula:


μ = mean(features)
σ² = variance(features)

x̂ = (x − μ) / √(σ² + ε)
y = γ x̂ + β


Same normalization formula, but applied differently.

---

# 9. BatchNorm vs LayerNorm

| Feature | BatchNorm | LayerNorm |
|--------|-----------|-----------|
| Normalization dimension | Across batch | Across features |
| Works best for | CNNs | Transformers |
| Depends on batch size | Yes | No |
| Used in | ResNet, CNN models | Transformers, NLP |

---

# 10. Visual Intuition

BatchNorm:


Batch of samples
↓
Normalize each feature across batch


LayerNorm:


Single sample
↓
Normalize all features inside it

# 12. Normalization in Training Pipeline

Our full training pipeline now becomes:


Initialize weights
↓
Forward pass
↓
Linear layer
↓
Normalization
↓
Activation
↓
Compute loss
↓
Backpropagation
↓
Optimizer update
↓
Repeat


Normalization stabilizes **both forward activations and backward gradients**.

---

# 13. Interview Explanation

**What is normalization in neural networks?**

Normalization techniques stabilize the distribution of activations during training by scaling them to have consistent mean and variance. This improves training stability, speeds up convergence, and helps mitigate vanishing or exploding gradients.

---

# 14. Interview Questions

### Q1

Why does BatchNorm speed up training?

Because it stabilizes activation distributions, allowing the network to use larger learning rates.

---

### Q2

Why do Transformers use LayerNorm instead of BatchNorm?

BatchNorm depends on batch statistics, which are unreliable for sequence models and small batches.

---

### Q3

Does BatchNorm remove the need for careful initialization?

It reduces sensitivity to initialization but does not completely eliminate the need.

---

# 15. Key Takeaway

Normalization keeps neural network activations **well-scaled during training**, leading to:


stable gradients
faster convergence
better training dynamics
