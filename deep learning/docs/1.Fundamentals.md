# 1. Neuron Basics

**Equation**

$$
y = f(Wx + b)
$$

- **W**: weights  
- **b**: bias  
- **f**: activation (ReLU, sigmoid, etc.)

**Notes**
- A **layer** = set of neurons → vectorized forward pass.  
- **Loss**: error per sample.  
- **Cost**: average loss over the dataset.  

**Example: Binary Cross-Entropy loss**

$$
\mathcal{L}(y, \hat{y}) = - \big[ y \log(\hat{y}) + (1-y) \log(1-\hat{y}) \big]
$$

**Equation**


Perceptron

$$
y =
\begin{cases}
1 & \text{if } Wx + b > 0 \\
0 & \text{otherwise}
\end{cases}
$$


Modern Neuron
$$
y = f(Wx + b)
$$

Perceptron → Modern Neuron → MLP → DNN → CNN → RNN/LSTM/GRU → Transformer

# 2. Initialization

- Random init too small → vanishing.  
- Random init too large → exploding.  

**Xavier/Glorot Init** (good for sigmoid/tanh):  
$$
Var(W) = \frac{2}{n_{in} + n_{out}}
$$

**He Init** (good for ReLU):  
$$
Var(W) = \frac{2}{n_{in}}
$$

# 3. Forward Pass

**Flow**  
Input → Linear combination → Activation → Next layer.

**Example**

Input:  
$$
x = [x_1, x_2]
$$

Hidden neuron:  
$$
h = ReLU(w_1 x_1 + w_2 x_2 + b)
$$

Output neuron: sigmoid for probability.  


The **forward pass** is the process of feeding input data through the network to compute the output (prediction).  
It’s the inference step before we calculate the loss and start backpropagation.


## Forward Pass of a Single Neuron

**Equation**

$$
y = f(Wx + b)
$$

Steps:
1. **Input**: $x$ (features)  
2. **Multiply by weights**: $Wx$  
3. **Add bias**: $+b$  
4. **Apply activation function** $f$ (e.g., sigmoid, ReLU)  
5. **Output**: $y$



## Forward Pass in an MLP (Vectorized)

For a **2-layer MLP**:

**Hidden layer**  
$$
h = f(W_1 x + b_1)
$$

**Output layer**  
$$
\hat{y} = g(W_2 h + b_2)
$$

Where:
- $f, g$ = activation functions (e.g., ReLU in hidden, softmax in output).  
- $\hat{y}$ = prediction.  



## Forward Pass Steps in Training

- Input → **Layer 1**: compute activations.  
- **Layer 1 → Layer 2 → … → Layer N**: repeat weighted sum + activation.  
- **Final layer**: produce output (e.g., class probabilities).  
- **Loss function**: compare prediction with true labels.

# 4. Activation Functions

In a neural network, an activation function determines how the weighted sum of inputs and bias is converted into the output of a neuron, introducing non-linearity to the model.

## Why do we need them?
- Without activations, a neural network is just a linear model (no matter how many layers).  
- Activations introduce **non-linearity**, allowing networks to learn complex functions (e.g., images, language). 
- It decides whether the neuron should be activated(ON) or deactivated (OFF) 

## Common Activation Functions

### Sigmoid (Logistic)
$$
f(x) = \frac{1}{1 + e^{-x}}
$$

- Range: (0, 1)  
- Good for probabilities (binary classification)  
- Problems: vanishing gradients, slow training  

### Tanh (Hyperbolic Tangent)
$$
f(x) = \tanh(x) = \frac{e^x - e^{-x}}{e^x + e^{-x}}
$$

- Range: (-1, 1)  
- Zero-centered → better than sigmoid  
- Still suffers from vanishing gradients  

### ReLU (Rectified Linear Unit)
$$
f(x) = \max(0, x)
$$

- Most widely used in hidden layers  
- Pros: simple, efficient, avoids vanishing gradients (mostly)  
- Cons: “dying ReLU” problem (neurons stuck at 0)  

### Leaky ReLU
$$
f(x) =
\begin{cases}
x & \text{if } x > 0 \\
\alpha x & \text{if } x \leq 0
\end{cases}
$$

- Fixes dying ReLU by allowing small negative slope ($\alpha \approx 0.01$)  


### Softmax
$$
f(x_i) = \frac{e^{x_i}}{\sum_j e^{x_j}}
$$

- Converts outputs into probabilities (sums to 1)  
- Used in multi-class classification  


## How to Choose
- Hidden layers: ReLU (or Leaky ReLU, GELU)  
- Binary output: Sigmoid  
- Multi-class output: Softmax  

## Interview Soundbite
“Activation functions introduce non-linearity. Sigmoid and tanh were used historically but suffer from vanishing gradients. ReLU is the most popular today for hidden layers, while sigmoid and softmax are used at the output depending on the task.”

# 5. Loss Functions

A loss function quantifies the error between the model’s prediction and the true target for one training sample.


## Regression Losses

**Mean Squared Error (MSE)**  

$$
L = \frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2
$$

- Penalizes large errors heavily.  
- Used in regression.  

**Mean Absolute Error (MAE)**  

$$
L = \frac{1}{n} \sum_{i=1}^{n} \lvert y_i - \hat{y}_i \rvert
$$

- More robust to outliers than MSE.  



## Binary Classification Losses

**Binary Cross-Entropy (Log Loss)**  

$$
L = -\frac{1}{n} \sum_{i=1}^{n} \Big[ y_i \log(\hat{y}_i) + (1-y_i)\log(1-\hat{y}_i) \Big]
$$

- $\hat{y}_i$ = predicted probability.  
- Used with **sigmoid activation** in output.  



## Multi-Class Classification Losses

**Categorical Cross-Entropy**  

$$
L = - \sum_{i=1}^{n} \sum_{c=1}^{C} y_{i,c} \log(\hat{y}_{i,c})
$$

- $y_{i,c}$ = one-hot true label.  
- $\hat{y}_{i,c}$ = predicted probability for class $c$.  
- Used with **softmax activation**.  



## Margin-Based Losses

**Hinge Loss (SVMs)**  

$$
L = \frac{1}{n} \sum_{i=1}^{n} \max(0, \, 1 - y_i \cdot \hat{y}_i)
$$

- Used for “maximum margin” classifiers.  



## Advanced (when needed)

- **Huber Loss** → mix of MAE + MSE, robust regression.  
- **KL Divergence** → measures difference between two probability distributions.  
- **Triplet Loss / Contrastive Loss** → used in embeddings (e.g., face recognition).  

# Cost Function
The cost function is the average of the loss values across all training examples.

While loss = error for a single sample, cost = error for the whole dataset (or a mini-batch).

# Formula Examples

## Mean Squared Error (MSE) – Regression

**Loss (single sample)**  
$$
Loss = (y - \hat{y})^2
$$

**Cost (all samples)**  
$$
Cost = \frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2
$$

## Binary Cross-Entropy (Log Loss) – Classification

**Cost (all samples)**  
$$
Cost = -\frac{1}{n} \sum_{i=1}^{n} 
\Big[ y_i \log(\hat{y}_i) + (1 - y_i) \log(1 - \hat{y}_i) \Big]
$$

# 6. Backpropagation

**Core idea**: Chain rule of calculus.  

**Steps**
1. Compute loss at output.  
2. Propagate gradients backward ($\partial L / \partial W$).  
3. Update weights:  
   $$
   W := W - \eta \cdot \frac{\partial L}{\partial W}
   $$
   where $\eta$ = learning rate.  

**Problems**
- **Vanishing gradients**: sigmoid/tanh shrink gradients → slow learning.  
- **Exploding gradients**: large weights → unstable training.  


# Backpropagation (Backprop)

##  What is it?

Backpropagation is the algorithm for training neural networks.  
It computes gradients of the loss w.r.t. weights and biases using the **chain rule of calculus**,  
then updates the weights via **gradient descent**.  



## Training Pipeline (Big Picture)

**Forward Pass → compute predictions**

$$
\hat{y} = f(Wx + b)
$$

**Loss Function → compare with true labels**

$$
L(\hat{y}, y)
$$

**Backward Pass (Backprop) → compute gradients**

$$
\frac{\partial L}{\partial W}, \quad \frac{\partial L}{\partial b}
$$

**Update Weights → Gradient Descent**

$$
W \leftarrow W - \eta \cdot \frac{\partial L}{\partial W}
$$

$$
b \leftarrow b - \eta \cdot \frac{\partial L}{\partial b}
$$



## Core Idea: Chain Rule

If we have:  

$$
z = Wx + b, \quad y = f(z), \quad L = loss(y, y_{true})
$$

Then by chain rule:

$$
\frac{\partial L}{\partial W} = 
\frac{\partial L}{\partial y} \cdot
\frac{\partial y}{\partial z} \cdot
\frac{\partial z}{\partial W}
$$



## Backprop in Multi-Layer Network

For a **2-layer MLP**:

**Hidden layer**

$$
h = f(W_1 x + b_1)
$$

**Output layer**

$$
\hat{y} = g(W_2 h + b_2)
$$

**Loss**

$$
L(\hat{y}, y)
$$

**Backprop steps**

- Compute output error:

$$
\delta_{out} = \frac{\partial L}{\partial \hat{y}} \cdot g'(z_2)
$$

- Gradients for output weights:

$$
\frac{\partial L}{\partial W_2} = \delta_{out} \cdot h^T
$$

- Propagate error to hidden:

$$
\delta_{hidden} = (W_2^T \cdot \delta_{out}) \cdot f'(z_1)
$$

- Gradients for hidden weights:

$$
\frac{\partial L}{\partial W_1} = \delta_{hidden} \cdot x^T
$$


## Why Backprop is Important

- **Efficient**: avoids recomputing derivatives from scratch.  
- Works for **any network depth**.  
- Core of modern optimizers (SGD, Adam, etc.).  

##  Interview Soundbite

“Backpropagation is the process of calculating gradients of the loss with respect to each parameter in a neural network using the chain rule. We start from the output layer and move backward, layer by layer, to update weights efficiently with gradient descent.”

# 7. Weight Update (Gradient Descent)



## What it is
After backpropagation gives us gradients  
$\frac{\partial L}{\partial W}, \; \frac{\partial L}{\partial b}$,  
we update weights in the **opposite direction of the gradient** (to minimize loss).  



## The Update Rule

For each parameter:

$$
W \leftarrow W - \eta \cdot \frac{\partial L}{\partial W}
$$

$$
b \leftarrow b - \eta \cdot \frac{\partial L}{\partial b}
$$

Where:
- **W** = weights  
- **b** = bias  
- **η** = learning rate  
- $\frac{\partial L}{\partial W}$ = gradient from backprop  


## Role of Learning Rate (η)

- **Too small** → very slow learning  
- **Too large** → overshoots, oscillates, may diverge  
- **Good choice** → steady convergence  
- Modern optimizers **adapt η automatically**  



## Variants of Gradient Descent

- **Batch Gradient Descent**  
  - Uses the whole dataset per update.  
  - Stable but **very slow**.  

- **Stochastic Gradient Descent (SGD)**  
  - Updates after **each sample**.  
  - Noisy but faster, helps escape local minima.  

- **Mini-Batch Gradient Descent (most common)**  
  - Uses **small batches** (e.g., 32/64 samples).  
  - Balance of efficiency + stability.  



## Optimizer Improvements

- **Momentum** → adds memory of past gradients → smoother updates.  
- **RMSProp** → scales learning rate by gradient history.  
- **Adam** → combines Momentum + RMSProp (default choice in DL).  

- **AdamW** → (Adam with decoupled weight decay)  
  - Fixes a subtle issue in Adam where **L2 regularization** was implemented as “L2 penalty on gradients” instead of true weight decay.  
  - In AdamW, weight decay is applied **directly to the weights**, independent of the gradient update.  
  - This leads to better generalization, especially in deep networks and transformers.  
  - Today, **AdamW is the default** choice for training large neural networks.  


## Big Picture

1. **Forward pass** → predict  
2. **Loss function** → compare  
3. **Backpropagation** → compute gradients  
4. **Weight update (GD/SGD/Adam)** → learn  
5. **Repeat** for many epochs until convergence  

## Interview Soundbite

“After backpropagation computes gradients, we update weights using gradient descent.  
Each weight is adjusted by subtracting a fraction (learning rate × gradient).  
Using mini-batches and optimizers like Adam makes training stable and efficient.”

# 8. Learning Rate Schedules

# Learning Rate

The learning rate tells the optimizer how big a step to take when updating the weights in the direction opposite to the gradient for a mini-batch.

## When the Learning Rate is Low
- Training is more stable and reliable.  
- Convergence is slow, since steps toward the minimum of the loss function are very small.  

## When the Learning Rate is High
- Training may fail to converge or even diverge.  
- Weight updates are too large, causing the optimizer to overshoot the minimum and make training unstable.  


## Why Schedules?
- A fixed learning rate (η) can be suboptimal.  
- Too high → divergence.  
- Too low → very slow convergence.  
- Solution: adjust η **over epochs** to balance exploration (high LR early) and convergence (low LR later).

## Common Schedules

**Step Decay**  
- Reduce η by a factor every k epochs.  
- Example: η ← η * 0.1 every 30 epochs.  
- Works well for classical CV tasks.

**Exponential Decay**  
- Smooth reduction each epoch.  
- η_t = η₀ * exp(-kt).  

**Cosine Annealing**  
- Learning rate follows a cosine curve.  
- Starts high, gradually decreases to near zero.  
- Often combined with **restarts** (Cosine Annealing with Warm Restarts, SGDR).  

**Warmup**  
- Start with a **small LR → gradually increase** for a few epochs.  
- Prevents instability early in training.  
- Widely used in **transformers and large models**.  


## Interview Soundbite
“Learning rate schedules let us start with a high learning rate to explore the parameter space, then gradually reduce it to converge stably. Cosine annealing with warmup is the de-facto choice for transformers today.”

# 9. Training Dynamics & Challenges

## Local Minimum
A point in the loss function where:  
- Gradient = 0  
- Loss is lower than nearby points  
- But not the absolute lowest possible (global minimum)  

Problem: Gradient descent can get stuck here (especially in shallow networks).  

## Global Minimum
- The absolute lowest loss across the entire parameter space.  
- In practice:  
  - Rarely found in deep nets (too high-dimensional).  
  - Good local minima are usually “good enough” — networks generalize well even if not at the global minimum.  

## Saddle Points
A point where gradient = 0 but:  
- Loss decreases in one direction  
- Loss increases in another  

This is like sitting on a mountain pass: flat locally, but not optimal.  

Modern deep nets (with millions of parameters) are more likely to get stuck in saddle points than in true bad local minima.  

## Why It Matters
In high-dimensional spaces (like deep nets), there are:  
- Many saddle points  
- Many flat regions (plateaus)  

Training success depends on escaping saddles and plateaus.  

## How We Handle It
- Stochastic Gradient Descent (SGD): noisy updates help escape saddles.  
- Momentum: pushes through small dips and plateaus.  
- Learning rate schedules (decay, warm restarts): balance exploration vs convergence.  
- Batch normalization and good initialization: reduce vanishing gradients and poor regions.  

## Interview Soundbite
“In training, gradients can vanish at points like local minima or saddle points. In modern deep networks, saddle points are a bigger challenge than local minima. SGD’s noise, momentum, and advanced optimizers help the model escape these traps and continue converging toward a good solution.”

# 10. Model Generalization

## Overfitting
When the model memorizes training data instead of learning patterns.

**Symptoms**
- Very low training loss  
- High validation/test loss  

**Example**
- Deep neural network with too many parameters trained too long  

## Underfitting
When the model is too simple to capture patterns.

**Symptoms**
- High training loss  
- High test loss  

**Example**
- Linear model trying to fit non-linear data  

## Regularization Techniques (to improve generalization)

Regularization refers to techniques used to reduce overfitting by adding constraints or penalties to the model, ensuring it generalizes well to unseen data.

Key Idea
Prevents the model from becoming too complex and memorizing training data.
Achieved by adding a penalty term to the loss (error) function.

**L1 Regularization (Lasso)**  
Adds penalty term:  
$$
\lambda \sum |W|
$$  
Encourages sparse weights (feature selection).  

**L2 Regularization (Ridge)**  
Adds penalty term:  
$$
\lambda \sum W^2
$$  
Prevents very large weights, stabilizes training.  

**Dropout**  
- Randomly drops neurons during training  
- Prevents co-dependency among neurons  

**Data Augmentation**  
- Artificially expand dataset (rotate/flip images, add noise, etc.)  
- Improves robustness  

**Early Stopping**  
- Monitor validation loss  
- Stop training before overfitting kicks in  

## Interview Soundbite
“Overfitting means the model memorizes the training set, underfitting means it is too simple to even fit the training data. We fight overfitting with regularization methods like L1/L2, dropout, data augmentation, and early stopping.”
