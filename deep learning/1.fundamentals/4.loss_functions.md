# 5. Loss Functions

A loss function quantifies the error between the model’s prediction and the true target for one training sample.


## Regression Losses

**Mean Squared Error (MSE)**  

$$
L = \frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2
$$

- Penalizes large errors heavily.  
- Used in regression.  

**Mean Absolute Error (MAE)**  

$$
L = \frac{1}{n} \sum_{i=1}^{n} \lvert y_i - \hat{y}_i \rvert
$$

- More robust to outliers than MSE.  



## Binary Classification Losses

**Binary Cross-Entropy (Log Loss)**  

$$
L = -\frac{1}{n} \sum_{i=1}^{n} \Big[ y_i \log(\hat{y}_i) + (1-y_i)\log(1-\hat{y}_i) \Big]
$$

- $\hat{y}_i$ = predicted probability.  
- Used with **sigmoid activation** in output.  



## Multi-Class Classification Losses

**Categorical Cross-Entropy**  

$$
L = - \sum_{i=1}^{n} \sum_{c=1}^{C} y_{i,c} \log(\hat{y}_{i,c})
$$

- $y_{i,c}$ = one-hot true label.  
- $\hat{y}_{i,c}$ = predicted probability for class $c$.  
- Used with **softmax activation**.  



## Margin-Based Losses

**Hinge Loss (SVMs)**  

$$
L = \frac{1}{n} \sum_{i=1}^{n} \max(0, \, 1 - y_i \cdot \hat{y}_i)
$$

- Used for “maximum margin” classifiers.  



## Advanced (when needed)

- **Huber Loss** → mix of MAE + MSE, robust regression.  
- **KL Divergence** → measures difference between two probability distributions.  
- **Triplet Loss / Contrastive Loss** → used in embeddings (e.g., face recognition).  

# Cost Function
The cost function is the average of the loss values across all training examples.

While loss = error for a single sample, cost = error for the whole dataset (or a mini-batch).

# Formula Examples

## Mean Squared Error (MSE) – Regression

**Loss (single sample)**  
$$
Loss = (y - \hat{y})^2
$$

**Cost (all samples)**  
$$
Cost = \frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2
$$

## Binary Cross-Entropy (Log Loss) – Classification

**Cost (all samples)**  
$$
Cost = -\frac{1}{n} \sum_{i=1}^{n} 
\Big[ y_i \log(\hat{y}_i) + (1 - y_i) \log(1 - \hat{y}_i) \Big]
$$
