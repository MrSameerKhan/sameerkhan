# 1. Neuron Basics

**Equation**

$$
y = f(Wx + b)
$$

- **W**: weights  
- **b**: bias  
- **f**: activation (ReLU, sigmoid, etc.)

**Notes**
- A **layer** = set of neurons → vectorized forward pass.  
- **Loss**: error per sample.  
- **Cost**: average loss over the dataset.  

**Example: Binary Cross-Entropy loss**

$$
\mathcal{L}(y, \hat{y}) = - \big[ y \log(\hat{y}) + (1-y) \log(1-\hat{y}) \big]
$$

**Equation**


Perceptron

$$
y =
\begin{cases}
1 & \text{if } Wx + b > 0 \\
0 & \text{otherwise}
\end{cases}
$$


Modern Neuron
$$
y = f(Wx + b)
$$

Perceptron → Modern Neuron → MLP → DNN → CNN → RNN/LSTM/GRU → Transformer
