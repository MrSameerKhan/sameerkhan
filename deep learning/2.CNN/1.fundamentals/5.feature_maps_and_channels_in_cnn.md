# 1. What is a Feature Map?

A **feature map** is the output produced by applying a **convolution filter** to an input.

Example:


Input Image
↓
Convolution Filter
↓
Feature Map


Each feature map highlights **specific patterns** detected in the image.

Examples of patterns:


edges
corners
textures
shapes


---

# 2. Mental Model

Think of filters as **pattern detectors**.

Example filters:


Filter 1 → vertical edges
Filter 2 → horizontal edges
Filter 3 → diagonal edges
Filter 4 → texture


Each filter produces **one feature map**.

So if we use:


64 filters


We get:


64 feature maps


Stacked together.

---

# 3. What is a Channel?

A **channel** represents one layer of information in the input.

Example:

RGB image:


Red Channel
Green Channel
Blue Channel


So input dimension:


Height × Width × Channels


Example:


224 × 224 × 3


---

# 4. Filter Depth Matches Input Channels

Each convolution filter must match the **depth of the input**.

Example input:


224 × 224 × 3


Filter size:


3 × 3 × 3


Because it must cover all channels.

Example filter:


Channel 1 weights
Channel 2 weights
Channel 3 weights


The filter processes **all channels simultaneously**.

---

1×1 + 2×0 + 3×0 + 4×1 = 5


### Channel 2


2×0 + 3×1 + 4×1 + 5×0 = 7


### Channel 3


1×1 + 1×1 + 0×1 + 2×1 = 4


Total output:


5 + 7 + 4 = 16


This produces **one pixel in the feature map**.

...


Example:


32 filters


Output:


Height × Width × 32


This increases the **depth dimension**.

---

# 12. Common Interview Questions

### Q1

What is the difference between a filter and a feature map?

Answer:

A filter is a set of weights used in convolution, while a feature map is the output produced by applying that filter.

---

### Q2

Why do CNNs use multiple filters?

Answer:

Multiple filters allow the network to detect different types of features simultaneously.

---

### Q3

Why must filter depth equal input channel depth?

Answer:

Because convolution operates across all channels simultaneously.
