# 1. ReLU in CNN

ReLU stands for:


Rectified Linear Unit


Formula:


ReLU(x) = max(0, x)


Meaning:


if x > 0 → keep value
if x ≤ 0 → output 0


---

# 2. Why ReLU is Used After Convolution

Convolution outputs **linear combinations of pixels**.

Example output:


-2 3 1
4 -1 2
0 5 -3


Apply ReLU:


0 3 1
4 0 2
0 5 0


Negative activations are removed.

This introduces **non-linearity**.

Without ReLU:


CNN would behave like a linear model


---

# 3. Mental Model for ReLU

Think of ReLU as a **feature gate**.


Important feature → pass through
Unimportant feature → block


Example:


edge strength = -2 → remove
edge strength = 4 → keep


So ReLU keeps only **strong feature activations**.

---

# 4. Numeric Toy Example

Feature map:


-1 2 3
4 -5 1
-2 6 2


Apply ReLU:


0 2 3
4 0 1
0 6 2


Feature responses remain **positive activations only**.

---

# 5. Why ReLU Helps Training

ReLU helps in three ways.

### 1. Prevents vanishing gradients

Sigmoid derivatives shrink.

ReLU derivative:


1 for positive inputs


This preserves gradients.

---

### 2. Sparse activations

Many neurons become zero.

Example:


0 2 3
4 0 1
0 6 2


Sparse representations improve efficiency.

---

### 3. Faster computation

ReLU requires only:


comparison with zero


No expensive exponentials like sigmoid.

---

# 6. Problem: Dying ReLU

If neuron output becomes negative:


ReLU(x) = 0


Gradient becomes:


0


Neuron stops learning.

This is called:


Dying ReLU


Solutions:


Leaky ReLU
ELU
GELU


---

# 7. Batch Normalization in CNN

BatchNorm stabilizes the **distribution of activations**.

Problem:

During training, activations keep shifting.

This causes:


unstable gradients
slow training


BatchNorm normalizes activations.

---

# 8. BatchNorm Formula

Given activation:


x


Compute:

Mean:


μ = average(x)


Variance:


σ²


Normalize:


x̂ = (x − μ) / √(σ² + ε)


Then scale and shift:


y = γx̂ + β


Where:


γ = learnable scale
β = learnable shift


---

# 9. Numeric Example

Activations:


2 4 6 8


Mean:


5


Variance:


5


Normalized output:


-1.34 -0.45 0.45 1.34


Now distribution becomes:


mean ≈ 0
variance ≈ 1


---

# 10. Why BatchNorm Helps CNN

BatchNorm provides:

### 1. Faster training

Stable distributions allow larger learning rates.

---

### 2. Reduced vanishing gradients

Normalization keeps gradients stable.

---

### 3. Regularization effect

Noise from batch statistics helps generalization.

# 13. Interview Explanation

### What is ReLU?

ReLU is an activation function that introduces non-linearity by outputting the input if it is positive and zero otherwise.

---

### What is BatchNorm?

Batch normalization normalizes layer activations using batch statistics to stabilize training and accelerate convergence.

---

# 14. Common Interview Questions

### Q1

Why is ReLU preferred over sigmoid?

Answer:

ReLU avoids vanishing gradients and is computationally efficient.

---

### Q2

Why is BatchNorm placed before ReLU?

Answer:

Normalizing activations before applying non-linearity stabilizes the distribution and improves training.

---

### Q3

Does BatchNorm remove the need for careful initialization?

Answer:

It reduces sensitivity but does not completely eliminate the need.
