04 Machine Learning
🧠
Model Inference API
OpenAI API · Workers
Keep inference in backend routes, not the browser. Centralize prompt templates, retries, and guardrails for predictable model behavior.
🧲
Vector Search
pgvector · Pinecone
Store embeddings and retrieve relevant context before generation. Start with pgvector in Postgres, move to Pinecone when scale demands it.
📐
Quality & Eval

Track output quality, latency, and cost. Run test sets against prompt/model changes to prevent regressions before shipping.
Features · Model outputs ▼
04.5 LLM Orchestration
🔗
LLM Frameworks
LangChain · LlamaIndex
Abstract over API differences between OpenAI, Claude, Gemini. Chain multiple steps, manage conversation memory, and inspect token usage. Start simple, add frameworks when you need multi-step reasoning.
💬
Prompt Management
Prompt Versioning · Templates
Store prompts in a database or version control. Separate system prompts from user input. Track which prompt version generated each output for debugging and analysis.
🤖
AI Agents
Tool calling · Function definitions
Let models call functions, execute tools, and reason over results. Use structured outputs for reliable parsing. Keep agent loops simple and add guardrails to prevent infinite loops.
⌨️
Coding Assistance
Inline completion · Refactor · Explain
Real-time code completion, multi-line suggestions, and natural-language commands. Uses project context via embeddings and LSP for accurate, scope-aware suggestions. Supports explain, refactor, and test generation.

Key Architectural Decisions
💡 Why one repo for frontend + backend?
Zero coordination overhead as a solo dev. Next.js full-stack collocates everything. Split into separate services when you hire or hit real scaling limits.
💡 Why managed Postgres, not SQLite?
Supabase/Neon are free to start and production-ready. Migrating from SQLite to Postgres when you need it is painful and time-consuming.
💡 Why not microservices?
You're one person. A monolith ships faster, is easier to debug, and can be decomposed later once domain boundaries are fully understood.
💡 When to add a separate backend?
When API routes get too heavy, or you need to expose the API to mobile apps or third parties. Extract to standalone Fastify or Hono then.
💡 How to handle external data sources?
For internal tools, data often lives in Sheets or Airtable. Use their SDKs in API routes and cache aggressively with revalidation tags.
💡 What's the real MVP cut line?
Next.js + Clerk + Prisma + Supabase + Vercel. Working internal tool in a weekend. Everything else is optional until proven necessary.
💡 Which LLM model should I use?
Start with OpenAI GPT-4 (most capable, best cost) or Claude (better for long contexts). Evaluate Gemini or local models once you hit specific constraints. Lock in a model via config, not hardcoded, to swap later.
💡 Should I use LangChain or raw API?
Use raw OpenAI SDK for simple prompts. LangChain adds abstraction and memory management — add it when you need multi-step chains or conversation history, not before.
💡 How do I avoid runaway LLM costs?
Set strict token budgets per request. Use cheaper & faster models for validation. Cache expensive operations. Log every call with cost. Set up billing alerts in the API provider dashboard.
💡 How should coding assistance get context?
Combine LSP (symbols, types, definitions) with RAG over project files and docs. LSP gives precise language semantics; embeddings retrieve relevant modules and patterns. Keep context windows bounded — prioritize open files and recently edited code. Use streaming for completions so users see suggestions as they type.
