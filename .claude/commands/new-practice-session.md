Create a new code practice session in the repo.

Ask the user for:
1. Phase number and name (e.g. 06_agents)
2. Session number and topic (e.g. 01_react_agent)

Then create the folder: code_practice/<phase>/<session>/

Create these 4 files:
- model.py — architecture skeleton with class and forward method
- train.py — training loop skeleton
- predict.py — CLI inference skeleton  
- all_details.md — with header status badge 🔧 Code-built, objective, tensor shapes, and how-to-run sections

Follow naming conventions from CLAUDE.md. Do not add explanatory comments in code.
